# ProdoBuds ⏱️

A social productivity app for iOS. Record time-lapse videos of your daily tasks, like studying, working out or cleaning, and share them with friends. Seeing each other's progress keeps everyone motivated.

Built by a team of 3 as a project at UT Austin (Spring 2026) 
Ernest Ramos, Jean-Claude Bissou, and Andy Trinh

## Running Locally
1. Clone the repo and open `ProdoBuds.xcodeproj` in Xcode.
2. Create a Firebase project and add your own `GoogleService-Info.plist` (it's not included in this repo).
3. Build and run on a simulator or device.
